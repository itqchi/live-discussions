# Live Discussions

A cross-platform live discussion app with Clubhouse-style rooms, optional camera/video, and first-class browser support.

## Target architecture

- **Web:** Angular
- **Mobile:** React Native
- **API:** NestJS
- **Realtime media:** LiveKit
- **Database:** PostgreSQL
- **Presence/cache:** Redis
- **Storage:** S3-compatible object storage
- **Workspace:** Nx monorepo

Development is being bootstrapped incrementally, starting with shared room contracts and the create/join room flow.
